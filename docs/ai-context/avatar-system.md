# Система аватара (по коду, состояние на 21.11.2026: аспект + круг рун)

Ключевая часть продукта: единственное, что даёт ощущение игры. Направление — тотемное **low-poly животное**
на класс (фасетная геометрия, у каждой зоны своя заливка). Решения — в `decisions.md`.
Визуальные изменения проверяются через Playwright MCP по скриншотам `/dev/avatar?...&big=1` (скриншоты — в
`.playwright-mcp/`, исключено из git) + автотесты геометрии и разметки.

## 1. Поток данных

```
Character + attributes + character_skills + daily_state
  → computeAvatarParams()            entities/character/model/avatarEngine.ts
  → AvatarParams                     entities/character/model/avatarTypes.ts
  → <ModularAvatar params size/>     ui/ModularAvatar/ModularAvatar.tsx
      ├─ classArchetype === "explorer" → creatures/fox/FoxAvatar.tsx   (asset-driven пайплайн)
      └─ остальные 4 класса          → Creature*.tsx                    (СТАРЫЙ органический Безье-рендер, отвергнут)
```

Используется на HomePage (`size="lg"`, внутри `AttributeRuneRing` size 340) и в `/dev/avatar` (AvatarPlaygroundPage:
обычный режим — та же композиция, что в hero; `big=1` — голый аватар 820px без кольца для детального осмотра).
Header маленький аватар не рисует (иконка + уровень); кольцо рун там не подключается.

Playground: URL-параметры `class`, `level`, атрибуты (`strength` … `creativity`), `charId` (seed эффектов),
`big=1`, `silhouette=true`, `legacyFx=1` (= чекбокс «Старые эффекты атрибутов (v2)»). Кнопки пресетов: Новичок (все 1), Атлет (Str 14, End 12, Dis 10, остальные 2),
Учёный (Int 15, Foc 12, Cre 8, остальные 2), Душа компании (Soc 15, Cre 12, остальные 2), Всё на 18, Всё на 9,
и 7 пресетов «Аспект: {название}» (главный атрибут 15, два следующих по порядку strength→…→creativity
циклически — 6, остальные 2).
Поле «Character ID» — сменить seed и сравнить двух персонажей.

### AvatarIdentity и seed (`model/avatarIdentity.ts`)

`seedKey` = id персонажа (для эффектов атрибутов) + сиды 0..1 из FNV-1a(id): bodySeed, faceSeed, eyeSeed,
earSeed, tailSeed, patternSeed, colorSeed, proportionsSeed. Эффекты атрибутов берут PRNG
`fxRng(seedKey, "<атрибут>")` (FNV-1a → mulberry32) — один персонаж всегда одинаков, разные — разные.

### avatarEngine.ts — общий слой параметров

- `getEvolutionTier(level)` → 7 тиров: **1:** L1–2, **2:** L3–4, **3:** L5–9, **4:** L10–19, **5:** L20–34, **6:** L35–49, **7:** L50+.
- `attributeValues` — сырые значения 7 атрибутов (1..18): вход круга рун и (в архиве) эффектов v2.
- `aspect` — доминирующий атрибут `{ attribute, color, intensity } | null` (`model/aspect.ts`, см. §3); тот же
  движок ставит `palette.glow` = цвет аспекта и эффект `aura` (для старого рендера Creature\*).
- Прочие поля (`body`, `posture`, `face`, `markings`, `endurance`, `social`, `creativity`, `effects`, `skillImprints`,
  `currentMood`) — наследие органического рендера Creature\*; Лиса их не читает.

### Слои FoxAvatar (снизу вверх)

1. Фон тира: `CreatureShadow`, `CreatureAura` и rim light (силуэтный дубль ассета, статичный). Цвет и яркость —
   `applyAspectGlow(тир, params.aspect)`: цвет аспекта × intensity, без аспекта — мягкий белый `#e2e8f0` × 0.5;
   в обоих случаях минимум `ASPECT_GLOW_FLOOR` (rim 0.85 / 3.5px, аура 0.55 / r 95). Тировые искры (кол-во,
   радиус, центр — **только от тира**): тёплые оранжевые + нейтральные белые (бывшие cyan — cyan отдан Intelligence).
2. Ассет тела — группа `avatar-body-group` (CSS-дыхание). Заливка = `defaultFill` ассета; единственное исключение —
   **кончики хвостов**: при наличии аспекта тёплые полигоны зон хвоста (`tail`, `tailTip`, `tailArray`; тест
   `isWarmAccent` с мягким порогом: тон 300°–70°, насыщенность > 0.12, светлота > 0.12) перекрашиваются в тон и
   насыщенность аспекта с сохранением светлоты (`tintToColor`). Без аспекта — как в ассете. Таких полигонов:
   L1 0, L2 15, L3 0, L4 38, L5 339.
3. Только при `legacyAttributeFx` (Playground): `AttributeFxLayer` back / front / overlay + контраст торса Strength.

## 3. Атрибуты: аспект + круг рун (ТЕКУЩЕЕ РЕШЕНИЕ, 21.11.2026)

Тело аватара не несёт эффектов атрибутов. Атрибуты видны двумя каналами:

**Аспект** (`entities/character/model/aspect.ts`, общий для всех классов):

- `ATTRIBUTE_COLORS`: strength `#ef4444`, endurance `#22c55e`, intelligence `#38bdf8`, focus `#2dd4bf`,
  discipline `#facc15`, social `#f472b6`, creativity `#a78bfa`. `ATTRIBUTE_ORDER` = этот порядок
  (strength, endurance, intelligence, focus, discipline, social, creativity), `ATTRIBUTE_LABELS_RU`.
- `getAspect(attrs)` — атрибут с максимумом, только если максимум ≥ 3 **и строго больше второго по величине**;
  любая ничья наверху → `null` (порядок атрибутов для ничьей не используется). «Всё на 9/18» — без аспекта.
- `getAspectIntensity(v)` — 3 → 0.35, 18 → 1.0, линейно.
- `applyAspectGlow(tierGlow, aspect)` — цвет rim light и ауры = цвет аспекта, opacity × intensity. Без аспекта —
  `NEUTRAL_GLOW_COLOR` `#e2e8f0` с фиксированной интенсивностью 0.5 (все классы; старый рендер — через
  `palette.glow`). У ранних тиров rim/аура = 0 (лиса L1), поэтому всегда действует минимум `ASPECT_GLOW_FLOOR` —
  у «Новичка» на L1 теперь тоже есть белый контур. Cyan `#38bdf8` в свечении означает только Intelligence.
- Заливка тела и фасеты не меняются (кроме кончиков хвостов, §2). Playground показывает «Аспект: … · интенсивность …» под аватаром.

**Круг рун** (`entities/character/ui/AttributeRuneRing/`):

- `runeGlyphs.ts` — 7 глифов (viewBox 24, прямые линии, stroke 2, round caps, без заливки; кроме точки r=1.5 у
  Intelligence и окружности r=7 у Focus): Сила — треугольник + черта; Выносливость — щит-пятиугольник;
  Интеллект — ромб с точкой; Фокус — окружность + 4 штриха прицела; Дисциплина — квадрат + вертикаль;
  Социальность — два ромба + линия; Креативность — четырёхконечная звезда (одним контуром).
  Рамка — шестиугольник (вершина вверх), засечки на 18 — снаружи рамки сверху/снизу/слева/справа.
- `runeLayout.ts` — состояния: v=1 серый `#64748b` 0.25; 2–5 цвет, opacity 0.7→0.85; 6–11 0.9 + рамка 0.6;
  12–17 + свечение 4px; 18 — 1.0, свечение 8px, рамка 1.0, засечки. Руна аспекта ×1.15. Раскладка: радиус
  `size × 0.46`, strength сверху, далее по часовой; если руна (квадрат 28px) пересекает bbox аватара —
  радиус растёт шагом 0.5px до минимального непересекающего. Контейнер = max(size, 2·reach), где
  reach = hypot(R + s/2, s/2) + 3px (запас на поворот спицы и парение — иначе горизонтальный скролл при 45°).
- `AttributeRune.tsx` — одна руна (`attribute`, `value`, `size`; свечение масштабируется от 28px; `plain` — только
  глиф полным цветом, для иконок навыков). Её используют кольцо, карточки характеристик (24px) и карточки
  навыков (16px), поэтому руна везде выглядит одинаково.
- `AttributeRuneRing.tsx` — props `attributes`, `size`, `children` (аватар по центру, размер не меняется; bbox
  меряется `ResizeObserver`), `showAspectSigil`. Тултип «Сила · 14» по наведению / фокусу / тапу, ставится с
  внутренней стороны руны — по её ТЕКУЩЕМУ положению (угол поворота читается при открытии).
  **Движение (только CSS, React не перерисовывается покадрово):**
  - кольцо вращается по часовой, оборот 120 с. Каждая руна — на своей «спице» от центра (`.spoke`, все в фазе);
    общий вращающийся блок не годится: его прямоугольник переполнения при 45° давал горизонтальный скролл;
  - компенсирующий поворот `.upright` держит глифы вертикально;
  - парение `.float`: translateY ±3px, 3.6 с, ease-in-out, фаза руны i = i × 0.5 с (отрицательный delay);
  - руны ≥ 12 «дышат»: радиус свечения ±25%, 4 с (`AttributeRune breathe`, CSS-переменные `--rune-glow`);
  - пауза вращения и парения, пока открыт тултип (`.paused`, `animation-play-state`); дыхание не паузится;
  - вспышка 400 мс при переходе руны в более высокое состояние сохранена;
  - `prefers-reduced-motion: reduce` — всё кольцо и сигил неподвижны.
    При вращении руны проходят над пустыми углами bbox аватара; силуэт лисы не задевают ни при каком угле
    (макс. радиус силуэта 109px против 131px у внутреннего края рун с учётом парения; замер L1–L5).
- `AspectSigil.tsx` — руна аспекта крупно ПОЗАДИ аватара (под всем SVG аватара, над фоном страницы), по центру.
  Диаметр = 0.78 × size кольца (`ASPECT_SIGIL_FACTOR`); viewBox ±20 единиц вмещает и засечки 18, чтобы они не
  доставали до рун. Состояния как у руны (рамка ≥ 6, свечение ≥ 12, засечки на 18), масштаб под размер; толщина
  линий пропорциональна, не тоньше 2px. Цвет аспекта, opacity 0.18 (v=3) → 0.45 (v=18). Вращение по часовой,
  60 с на оборот — на внутренней `<g>` (вращать сам `<svg>` нельзя: та же проблема с переполнением). Нет аспекта →
  не рисуется. Показывается в hero и в Playground (обычный режим и `big=1`, там диаметр = 0.78 × 820).
- Hero: кольцо size 340 вокруг аватара `lg` 200×240; парит аватар, руны вращаются по орбите. Обёртка hero раньше
  была 180×180 с `overflow: hidden` и обрезала аватар 200×240 — убрано. На 360px кольцо (~353px) шире контента
  секции — боковые руны частично обрезаны (открытая задача).

**Карточки характеристик** (HomePage): слева от названия `AttributeRune` 24px с текущим значением; названия — как
в тултипах (`ATTRIBUTE_LABELS_RU`); число окрашено в цвет атрибута. Названия никогда не обрезаются
(`min-width: max-content`, без многоточия): при вьюпорте < 420px сетка в 1 колонку, ≥ 420px — 2 колонки
`minmax(0, 1fr)`; промежутки в шапке карточки 6px — при 420px ровно хватает на «Выносливость» (шрифт тот же).

**Навыки** (`model/skillPresentation.ts`, `ui/SkillBadge/`):

- `getSkillRank(level)`: 1–2 Новичок, 3–5 Ученик, 6–9 Подмастерье, 10–14 Мастер, 15+ Грандмастер.
- `detectSkillIconCategory(name)` — ключевые слова (рус. основы — подстрока; короткие англ. — с начала слова):
  code, running, fitness, reading, language, driving, design, video, music, marketing, meditation.
- `getSkillIcon(name, primaryAttribute)` — категория → иконка `lucide-react` (`SKILL_ICON_COMPONENTS`): code →
  Code2, fitness → Dumbbell, running → Footprints, reading → BookOpen, language → Languages, driving → Car,
  design → Palette, video → Clapperboard, music → Music, marketing → TrendingUp, meditation → Flower2.
  Цвет — основной атрибут, stroke-width 2, размер 0.8 × слота (у lucide нет полей, как у руны). Без совпадения —
  глиф руны основного атрибута; навык без атрибута — нейтральная точка `#e2e8f0`.
- `pickTitleSkill` — макс. уровень → больше total_xp → позже last_practiced_at. `toSkillView` — id атрибутов
  навыка (`character_skills.primary_attribute_id` / `secondary_attribute_id`, теперь выбираются репозиторием) → коды.
- `SkillIcon` — иконка в кольце формы (прогресс = Форма %, цвет основного атрибута).
- `SkillTitlePlate` — табличка под кругом рун в hero и Playground: иконка 20px в кольце 28px +
  «{ранг} · {навык}». Нет навыков — ничего не рендерится. В Header не подключается.
- `SkillCard` — строка в разделе «Навыки» HomePage: иконка в кольце 32px, название, «ур. N · ранг», «Форма N%»,
  справа руны 16px атрибутов навыка (состояние — по текущему значению атрибута). EmptyState при 0 навыков сохранён.
- Playground: «Тестовые навыки (титул и карточки)» — 0–3 навыка (название, уровень, форма, атрибут), URL `skills=N`.

Проверка 21.11.2026 (Playwright, HomePage с подменённой сессией/REST + Playground, 390 и 1280 px, 6 пресетов):
руны не пересекают bbox аватара, не выходят за экран, горизонтального скролла нет (замер DOM на каждом кадре).

## 3b. Эффекты атрибутов на теле v2 — ОТЛОЖЕНО (архив, `ui/ModularAvatar/attributeFx/`)

Отложено 21.11.2026 (не отменено): см. decisions.md. Тег `avatar-attribute-fx-v2`, ветка
`archive/avatar-attribute-fx-v2`; код остаётся в `attributeFx/` и рендерится только при
`<ModularAvatar legacyAttributeFx />` — включается чекбоксом «Старые эффекты атрибутов (v2)» в Playground.

Один набор эффектов для всех классов. В `attributeFx/` нет ничего специфичного для лисы; существо подключается

### Анатомия (всё вычисляется геометрически, в `anatomy.ts`)

`CreatureAnatomy = { polygons, zones: { head, torso, eyes?, limbs?, tail? }, viewBox }`. Производные:

- **forehead** — полигоны head с центроидом в верхних 45% bbox головы и центральных 50% ширины; **foreheadCenter** — их центроид.
- **nape** — полигоны torso в верхних 30% bbox торса, 40% ближайших к центроиду головы.
- **chestPoint** — центроид 15% полигонов torso, ближайших к голове.
- **eyePoints** — центроиды связных групп eyes (близкие группы сливаются, до 2); фолбэк — 2 точки на 40% высоты
  головы, ±20% ширины.
- **silhouetteBBox**, **silhouetteHull** (выпуклая оболочка), **adjacency** (соседи по 2 общим вершинам, допуск 0.5),
  **sharedEdges**, **outerEdges** (рёбра одного полигона = силуэт).
- Нет head/torso — фолбэк по верхней/средней части силуэта; нет eyes/limbs/tail — эффекты используют свои фолбэки.

Ступени: `fxStep(v, max)` → v=1: 0 (эффект не рисуется), v=18: max, иначе `floor((v−1)/17 × max)`, но ≥1 при v≥2.

Палитра: body = `CLASS_BODY_PALETTE[класс].light`, accent = `CLASS_FORMATION_COLOR[класс]` (explorer `#f59e0b`,
янтарь кончика хвоста), light = `#cfe8ff` (общий). Других цветов в эффектах нет (только их осветления/затемнения

### Визуальный обзор 21.11.2026 (L1, L3, L5 × 6 пресетов; ничего не исправлялось)

- Strength: гребень хорошо читается на L3 (спина); на L1 — мелкая «гребёнка» у уха; на L4/L5 фолбэк ставит шипы
  поперёк морды («зубы»/«усы»). При Strength=2 один шип становится широким плоским треугольником (ширина основания
  = доля всей цепочки рёбер).
- Intelligence: на L1/L3 читается как сетка на лбу; на L5 «лоб» — маленький кусок на макушке, сеть сжимается в белое пятно.
- Focus: виньетка заметна от ~12, блики глаз — маленькие белые точки; при 9 почти не виден.
- Endurance: стежки читаются на L1/L3, на L5 теряются в мелкой сетке.
- Discipline: после разделения пространства кристаллы стоят внизу/по бокам и читаются; на L3+ к ним прилипают тировые искры.
- Social: созвездие читается как «звёзды над головой»; при 1–2 звёздах — одиночная точка с длинной нитью к груди
  (выглядит как случайный провод).
- Creativity: самый яркий элемент; при 8+ на L1 доминирует (неоновая ломаная по боку); при малых значениях одно
  оранжевое ребро похоже на царапину/шрам.
- Конфликт цветов: accent (янтарь) у Strength, Creativity и Discipline + оранжевые кончики хвостов L5 + тёплые тировые
  искры — всё одного цвета, на L5 сливается.
