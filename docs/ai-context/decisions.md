## ✅ Принятые решения (хронология)

### Продукт и стек

- **15.07.2026** — Стратегия: AI-RPG, mobile-first PWA, React+TS+Vite+Supabase, закрытая бета с друзьями,
  монетизация после удержания, накопленный опыт не отнимается, Level навыка отдельно от Form.
- **07.08.2026** — Окружение: ESLint/Prettier/EditorConfig, commitlint+husky, GitHub Actions.
- **11.08.2026** — Схема БД, сиды, RLS, email-auth; CI временно отключён (падает без тестов).
- **сентябрь 2026** — Google OAuth (настроен владельцем).
- **09.09.2026** — Онбординг одним атомарным RPC `complete_onboarding` (SECURITY DEFINER, auth.uid() внутри).
- **11.09.2026** — Auth Gate: 4 состояния; признак онбординга — наличие `characters`. Регистрация перенесена в **конец**
  онбординга (человек сначала создаёт персонажа). Редирект ready→/app только с гостевых путей.
- **14.09.2026** — `complete_quest` переписан из 4 клиентских вызовов в одну атомарную идемпотентную SQL-транзакцию.
  Кривая уровня `(n+1)·100` (200 XP до L2 ≈ 13 квестов — слишком медленно) заменена на **10·N·(N−1)**.
- **15.09.2026** — Пересмотр модели: атрибуты без progress-bar, +1 за квест (не +xp_reward); навыки в
  `character_skills` (свободное имя, часы, Level из XP, Form из last_practiced_at; `user_skills` удалена);
  XP навыка по часам; History убрана из нижнего меню (Главная | План | Отчёт).
- **16.09.2026** — `calculate_quest_effects` — чистый расчёт отдельно от записи; навык тегается 1–2 атрибутами
  (выбор пользователя); characterXp = часы×10, skillXp = часы×20×formMultiplier.
- **выжимка** — Онбординг больше НЕ создаёт строки `character_skills` (навыки только из реальных квестов). _Не реализовано._
- **выжимка** — 7 атрибутов окончательны для MVP (Wealth — после MVP). Атрибуты 1–18, старт 1.
- **выжимка** — AI-слой отложен до проверки базовой механики; затем: история прогресса → AI-слой.

### Аватар

- **16.09.2026** — Аватар как параметрический векторный рендер из `AvatarParams` (engine отдельно от рендера).
- **20.09.2026** — 7 тиров эволюции: L1–2, L3–4, L5–9, L10–19, L20–34, **L35–49, L50+** (добавлены, т.к. L20 достигается
  за 2–4 месяца). Расчёт: при ~3.5 ч/день L20 ≈ 3.5 мес, L35 ≈ 11 мес, L50 ≈ 23 мес.
- **20.09.2026** — Поворот к **low-poly** (ветка `feature/lowpoly-avatar-style`), тотемные животные:
  Warrior=Волк, Creator=Ворон, Explorer=Лиса (эталон), Strategist=Сова, Wanderer=Олень. Каждое животное — своя папка
  `creatures/<animal>/`, ModularAvatar только выбирает существо.
- **23.09.2026** — **Asset-driven**: на тир — готовый SVG (векторизация AI-референса), зоны размечены вручную id групп.
- **24.09.2026** — 5 ассетов Лисы (L1 клубок, L2, L3, L4 двуногая, L5 кицунэ); **Zero Mesh Mutation**; **FX-матрица**
  (rim glow, частицы, аура, цветокоррекция) различает формы с одинаковым силуэтом; смена тира — мгновенная замена ассета.
- **03.10.2026** — Зоны берутся только из `<g id>` SVG через `annotateFoxZones.mjs`; никаких захардкоженных bbox.
- **04.10.2026** — Endurance = шрамы + вены на ногах (1..5 на всю фигуру); Focus = DoF + виньетка + частицы;
  Discipline без наклона.
- **05.10.2026** — Discipline = 6 CSS-3D кристаллов на безопасном поясе; палитры тела по классам (`CLASS_BODY_PALETTE`).
- **выжимка** — Арка лисы (kitsune): свернувшийся лисёнок → четвероногая → переход к прямохождению → двуногая
  лиса-гуманоид → кицунэ с несколькими хвостами. Переход тира прячется за вспышкой/частицами.
- **выжимка** — Каждый класс: свой цвет тела + контрастный акцент. Волк: красное тело, белые акценты.
- **выжимка** — Финальная спецификация атрибутов Лисы (заменяет все ранние варианты): см. `avatar-system.md` §3.
  Strength, Intelligence, Focus, Endurance, Discipline, Creativity — ПРИНЯТЫ; Social — В РАБОТЕ.
- **выжимка** — Система частиц должна нести независимые параметры (кол-во от тира, радиус от Focus, регулярность от Discipline).
- **выжимка** — Волк: референсы плоские low-poly, строго анфас, спокойная прямая поза, пустой чёрный фон.
- **выжимка** — Птицы (Ворон, Сова) — своя логика крыльев.
