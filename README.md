# Dayforge

> RPG-система развития реальной жизни.

Dayforge — это приложение, которое превращает ежедневные действия пользователя в развитие игрового персонажа.

---

## Технологии

- React 19
- TypeScript
- Vite
- React Router
- Zustand
- TanStack Query
- React Hook Form
- Zod
- Supabase (в разработке)

---

## Требования

- Node.js 22+
- npm

---

## Установка

```bash
npm install
```

---

## Запуск

```bash
npm run dev
```

---

## Проверка проекта

```bash
npm run lint

npm run typecheck

npm run test

npm run build
```

или

```bash
npm run verify
```

---

## Переменные окружения

Создай

```
.env.local
```

на основе

```
.env.example
```
