# Социальный слой: имя, серия, друзья

## Как устроено сейчас (изучено 28.11.2026, до изменений)

- **Имя персонажа** — `characters.name text not null`. Задаётся в онбординге: шаг «Класс»
  (`features/onboarding/ui/ClassStep.tsx`, поле «Имя персонажа»), zod-правило `trim().min(2).max(30)` без ограничения
  символов (`features/onboarding/model/schema.ts`). На сервере `complete_onboarding` (`20261127150000`) имя не
  проверяет. Смены имени нет.
- **Где показывается персонаж:** главная (`pages/HomePage`) — она же «страница персонажа»: кольцо рун + сигил +
  `ModularAvatar`, под ним `SkillTitlePlate` (ранг + навык максимального уровня), затем имя `h1`, класс, уровень и XP.
  `/app/character` — заглушка. В шапке — аватар-заглушка и уровень, имя только в aria-label; кнопка ведёт в настройки.
- **«Отчёт сдан» за дату** — есть строка `daily_reports(character_id, date)`. Её пишет только `save_daily_report`
  (`20261128120000`). `apply_day_report` (`20261127120000`) отчёт не пишет: клиент после применения AI-разбора
  отдельно вызывает `save_daily_report` (`DailyReportPage.finishDay` → `dailyReportRepository.completeDay`). Если этот
  второй вызов не дошёл, день остаётся «не сданным», хотя квесты начислены.
- **Пользовательская дата:** `profiles.day_start_time` + `profiles.timezone` (клиент — `getUserDayDate`).
- **Снимки:** `character_snapshots` пишет `_upsert_character_snapshot` (ядро начислений, онбординг).

## План (feature/friends-and-streak)

1. **Имя:** общие правила (2–20 символов, буквы любого алфавита, цифры, пробел, `-`, `_`, без двойных пробелов) на
   клиенте и сервере; бан-лист `banned_words` (нормализация: нижний регистр, ё→е, латинские двойники → кириллица,
   без разделителей) — только на сервере. `rename_character`, проверка в `complete_onboarding`. Имя крупно на главной
   над титулом и в шапке; секция настроек «Персонаж».
2. **Серия:** `apply_day_report` сам пишет `daily_reports` (текст разбора). `_streak_info`: серия назад от вчера
   (или от сегодня, если сдан), одна заморозка на неделю пн–вс, рекорд за 730 дней, «недавний обрыв».
   `get_my_streak()`, `character_snapshots.streak`. На главной — огонь + число, строка «Неделя», карточка «С
   возвращением».
3. **Друзья:** `profiles.friend_code` (8 символов без похожих), `profiles.share_daily_summary`, `friendships`
   (взаимная пара). RPC: добавить по коду, удалить, сменить код, мой код, список друзей, профиль друга. Данные друзей —
   только через RPC с отобранными полями; сводка дня — только числа и до 3 названий навыков.
4. **Приглашение:** `/invite/:code`, превью для неавторизованных (`get_invite_preview`, anon: имя + класс),
   `pendingFriendCode` в localStorage → автодобавление после онбординга/входа.
5. **UI:** вкладка «Друзья», профиль друга, секция настроек «Приватность».
