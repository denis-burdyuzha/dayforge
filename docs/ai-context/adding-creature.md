# Добавление и обновление зверя (SVG-пайплайн)

Все классы, кроме Explorer (лиса — свой размеченный по зонам рендер `FoxAvatar`), рисуются общим компонентом
`creatures/AssetCreatureAvatar.tsx` из SVG-ассетов. Сейчас: warrior → волк, creator → медведь, strategist → лев,
wanderer → олень.

## 1. Файлы

- Исходники: `src/assets/images/baseForm/<класс>/<зверь>L1.svg … <зверь>L5.svg` (например,
  `wanderer/deerL4.svg`). Пять тиров по уровням: L1 — 1–2, L2 — 3–9, L3 — 10–34, L4 — 35–49, L5 — 50+.
- Внутри SVG — только `<polygon>` с `points` и `fill` (или `style="fill:…"`), **без `transform`** на элементах
  (если редактор их добавил — «Объект → Трансформировать → применить»/Ungroup, затем сохранить). id полигонов
  желательны; полигоны без id получат стабильные id `<зверь>L<N>_p<индекс>`.
- Порядок полигонов в файле = порядок отрисовки (z-order). Цвета берутся как есть.
- Исходные SVG скрипт только читает; сгенерированные данные лежат в
  `src/entities/character/ui/ModularAvatar/creatures/<зверь>/assets/` (руками не править).

## 2. Разметка подкраски под аспект (`aspectAccent`)

Полигоны, которые должны окрашиваться в цвет аспекта (глаза, кристаллы, кончики, светящиеся детали), собираются в
группу с id `aspectAccent`. В Inkscape:

1. Выделить нужные полигоны (Shift+клик, или «Правка → Выделить такие же → Цвет заливки»).
2. `Ctrl+G` — сгруппировать.
3. Открыть «Объект → Свойства объекта» (`Ctrl+Shift+O`), в поле **ID** написать `aspectAccent`, нажать
   «Установить».
4. Сохранить как «Обычный SVG».

Группа может быть вложенной и содержать подгруппы — учитываются все полигоны внутри на любой глубине. Светотень
сохраняется автоматически: каждый полигон получает оттенок аспекта, но свою светлоту (OKLCH), разброс оттенка и
насыщенности внутри группы сохраняется — кристаллы остаются гранями, градиенты градиентами. Без группы зверь
работает, просто без подкраски (скрипт предупредит).

## 3. Новый зверь

1. Положить SVG в `src/assets/images/baseForm/<класс>/`.
2. Добавить запись в `scripts/creatures.config.mjs`:
   `{ classId, animal, sourceDir, filePrefix, outDir: "src/entities/character/ui/ModularAvatar/creatures/<зверь>/assets" }`.
3. `npm run build:assets` — сгенерирует `<Зверь>L{1..5}AssetData.ts` и `<зверь>Assets.ts`.
4. FX-матрица `creatures/<зверь>/<зверь>FxMatrix.ts` (обычно `{ ...WOLF_FX_MATRIX }`).
5. Одна запись в `creatures/creatureRegistry.ts`: `classId → { animal, label, tierAssets, fxMatrix, tierNames }`.
6. Проверка: `/dev/avatar?class=<classId>&level=N&big=1` — рядом с аспектом выводится «aspectAccent: N полигонов»
   и имя файла ассета; тесты `npm test`.

## 4. Обновить зверя / добавить недостающий тир

Нет файла тира — используется ближайший нижний (скрипт предупреждает: `WARN L4: no deerL4.svg — uses L3`).
Положить недостающий SVG (например, `wanderer/deerL4.svg`) или обновлённую разметку и запустить
`npm run build:assets` — код менять не нужно. Повторный запуск без изменений SVG даёт нулевой diff.

Вывод скрипта по каждому тиру: `полигонов / в aspectAccent / какой файл`.
