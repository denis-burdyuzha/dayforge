# Продукт — Dayforge

Источник: `.ai-import/obsidian/Dayforge_Product_Strategy_Obsidian.md` (15.07.2026) + решения владельца
(выжимка из чата, новее файлов Gemini). Это сжатие, а не копия стратегии.

## Видение

- **Формулировка:** AI-RPG, в которой реальные действия пользователя развивают его персонажа.
- **Обещание:** расскажи, как прошёл день, — система превратит действия в опыт, навыки и развитие персонажа.
- **Главный принцип:** сначала добиться, чтобы 10 человек не хотели пропускать вечерний отчёт; только потом
  строить большую игру. Риск №1 — «разработка игры вместо продукта».
- Три мотива: видеть свой прогресс; удовольствие от развития персонажа; соревнование с друзьями.
- Серьёзный инструмент саморазвития в RPG-оболочке, не «трекер привычек с уровнями».

## Основной цикл

1. Утро: план дня → квесты.
2. День: отметка выполнения (необязательно).
3. Вечер: отчёт о дне.
4. Подтверждение: пользователь подтверждает/исправляет начисления. До подтверждения ничего не начисляется.
5. Награда: XP персонажа, XP навыков, атрибуты, уровень, развитие аватара.

Текущая реализация цикла — **без AI**: план вручную → квесты (навык + часы) → `complete_quest` → XP →
LevelUp → вечерний отчёт (свободный текст, только сохраняется). См. architecture.md.

## Принципы прогресса (утверждены)

- Накопленный опыт никогда не отнимается. Невыполненный квест = нет награды, но и нет штрафа.
- Навык: Level (накопленный) отдельно от Form (текущая форма). Form затухает после 3 дней простоя,
  пол 20%, влияет ТОЛЬКО на множитель будущего XP навыка.
- Навык создаётся пользователем на квесте и тегается 1–2 атрибутами (выбор пользователя).
- XP: characterXp = часы × 10; skillXp = часы × 20 × formMultiplier.
- Атрибуты — целые 1–18, старт 1, +1 к тегнутым атрибутам за квест.
- Кривая уровня: total_xp(N) = 10 × N × (N − 1).
- 7 атрибутов (финально для MVP): strength, endurance, intelligence, discipline, focus, social, creativity.
  Wealth — кандидат после MVP. (В стратегии от 15.07 был «Баланс» — заменён этим набором.)
- Онбординг НЕ создаёт навыки: навыки появляются только из реальных квестов. _(В коде пока создаёт — см. progress.md.)_
- Дневное состояние (energy/mood, таблица `daily_states`) — только позитивный бонус-слой, никогда не
  приглушает аватар. Сейчас не используется.

## MVP (по стратегии; статус — в progress.md)

- Auth + онбординг (имя, класс, направления). ✔ реализовано.
- Планирование дня и квесты. ✔ вручную (без AI).
- Вечерний отчёт + подтверждение. ◐ отчёт есть, AI-анализа и подтверждения начислений нет.
- Прогресс: уровень, атрибуты, навыки, ✔; история начислений/дней ✗; серии ✗; достижения ✗.
- Персонаж: несколько классов и стадий, 2D, без редактора внешности и 3D. ◐ (готова только Лиса).
- Социальное: друзья, приглашение по ссылке, недельный рейтинг «импульса» (не общий XP). ✗
- Системное: напоминание, удаление аккаунта, приватность, аналитика. ✗

## Сознательно отложено

- **AI-слой целиком** (генерация квестов из текста, извлечение навыков/событий из отчёта, план vs факт,
  уточняющие вопросы) — до доказательства базовой механики на живых людях.
- Монетизация (ориентир 499 ₽ / $7–9 в мес) — только после подтверждённого удержания.
- Социальная часть, рейтинг, боссы, привычки, проекты, AFK-режим.
- Звук, вибрация, event bus, «GameEvent»-типы.
- Цифровой аватар с камеры / генерация изображений.
- Графики, интеграции, голос, фото, инвентарь, валюта, глобальный рейтинг, гильдии, нативные приложения.

## Метрики раннего успеха (стратегия)

Главная: подтверждённые дневные отчёты на активного пользователя в неделю.
Первые 10 тестировщиков: ≥6 отправили >1 отчёта; ≥4 пользуются через неделю; ≥2 сами позвали друга.
Сигнал остановки: 30–50 подходящих людей попробовали, почти никто не вернулся после улучшений.
