# Система аватара (по коду, состояние на 21.11.2026)

Ключевая часть продукта: единственное, что даёт ощущение игры. Направление — тотемное **low-poly животное**
на класс (фасетная геометрия, у каждой зоны своя заливка). Решения — в `decisions.md`.
Визуально в последних сессиях ничего не проверялось (только код + автотесты геометрии и разметки).

## 1. Поток данных

```
Character + attributes + character_skills + daily_state
  → computeAvatarParams()            entities/character/model/avatarEngine.ts
  → AvatarParams                     entities/character/model/avatarTypes.ts
  → <ModularAvatar params size/>     ui/ModularAvatar/ModularAvatar.tsx
      ├─ classArchetype === "explorer" → creatures/fox/FoxAvatar.tsx   (asset-driven пайплайн)
      └─ остальные 4 класса          → Creature*.tsx                    (СТАРЫЙ органический Безье-рендер, отвергнут)
```

Используется на HomePage (`size="lg"`) и в `/dev/avatar` (AvatarPlaygroundPage).

Playground: URL-параметры `class`, `level`, атрибуты (`strength` … `creativity`), `charId` (seed эффектов),
`big=1`, `silhouette=true`. Кнопки пресетов: Новичок (все 1), Атлет (Str 14, End 12, Dis 10, остальные 2),
Учёный (Int 15, Foc 12, Cre 8, остальные 2), Душа компании (Soc 15, Cre 12, остальные 2), Всё на 18, Всё на 9.
Поле «Character ID» — сменить seed и сравнить двух персонажей.

### AvatarIdentity и seed (`model/avatarIdentity.ts`)

`seedKey` = id персонажа (для эффектов атрибутов) + сиды 0..1 из FNV-1a(id): bodySeed, faceSeed, eyeSeed,
earSeed, tailSeed, patternSeed, colorSeed, proportionsSeed. Эффекты атрибутов берут PRNG
`fxRng(seedKey, "<атрибут>")` (FNV-1a → mulberry32) — один персонаж всегда одинаков, разные — разные.

### avatarEngine.ts — общий слой параметров

- `getEvolutionTier(level)` → 7 тиров: **1:** L1–2, **2:** L3–4, **3:** L5–9, **4:** L10–19, **5:** L20–34, **6:** L35–49, **7:** L50+.
- `attributeValues` — сырые значения 7 атрибутов (1..18): единственный вход системы эффектов атрибутов.
- Прочие поля (`body`, `posture`, `face`, `markings`, `endurance`, `social`, `creativity`, `effects`, `skillImprints`,
  `currentMood`) — наследие органического рендера Creature\*; Лиса их не читает.

### Слои FoxAvatar (снизу вверх)

1. Фон тира: `CreatureShadow`, `CreatureAura` (cyan, opacity/радиус из FX-матрицы), rim light (силуэтный дубль ассета,
   cyan, статичный), тировые искры (кол-во, радиус, центр — **только от тира**).
2. `AttributeFxLayer layer="back"` → **SocialFx** (под телом).
3. Ассет тела (`resolveFill` = тон фасетов торса: Strength-контраст + Discipline-разброс) — группа `avatar-body-group`
   (CSS-дыхание).
4. `AttributeFxLayer layer="front"` → StrengthFx, EnduranceFx, CreativityFx, IntelligenceFx (в пространстве ассета),
   затем **FocusFx** (блики глаз + виньетка канваса).
5. `AttributeFxLayer layer="overlay"` → **DisciplineFx** (HTML/CSS-3D кристаллы, передний план).

## 3. Универсальная система эффектов атрибутов (`ui/ModularAvatar/attributeFx/`)

Один набор эффектов для всех классов. В `attributeFx/` нет ничего специфичного для лисы; существо подключается
адаптером анатомии (для лисы — `creatures/fox/foxAnatomy.ts`, ~40 строк).

| Файл                              | Роль                                                                                |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| `anatomy.ts`                      | тип `CreatureAnatomy`, `buildAnatomy`, производная геометрия (`getAnatomyGeometry`) |
| `fxContext.ts`                    | `createFxContext`: анатомия + палитра + значения + seed + трансформ + зонды силуэта |
| `fxPalette.ts`                    | `getFxPalette(classId)` → body / accent / light (+ bodyLight, shadow)               |
| `fxSeed.ts`                       | `fxRng`, `fxStep`, `fxNorm`                                                         |
| `bodyTone.ts`                     | тон фасетов торса в заливке ассета (Strength-контраст, Discipline-разброс)          |
| `compute<Attr>.ts`                | чистая геометрия каждого эффекта (тестируется)                                      |
| `<Attr>Fx.tsx`                    | рендер эффекта                                                                      |
| `AttributeFxLayer.tsx`            | сборка слоёв back / front / overlay                                                 |
| `attributeFx.invariants.test.tsx` | инварианты на L1–L5 × 6 пресетов (см. progress.md)                                  |

### Анатомия (всё вычисляется геометрически, в `anatomy.ts`)

`CreatureAnatomy = { polygons, zones: { head, torso, eyes?, limbs?, tail? }, viewBox }`. Производные:

- **forehead** — полигоны head с центроидом в верхних 45% bbox головы и центральных 50% ширины; **foreheadCenter** — их центроид.
- **nape** — полигоны torso в верхних 30% bbox торса, 40% ближайших к центроиду головы.
- **chestPoint** — центроид 15% полигонов torso, ближайших к голове.
- **eyePoints** — центроиды связных групп eyes (близкие группы сливаются, до 2); фолбэк — 2 точки на 40% высоты
  головы, ±20% ширины.
- **silhouetteBBox**, **silhouetteHull** (выпуклая оболочка), **adjacency** (соседи по 2 общим вершинам, допуск 0.5),
  **sharedEdges**, **outerEdges** (рёбра одного полигона = силуэт).
- Нет head/torso — фолбэк по верхней/средней части силуэта; нет eyes/limbs/tail — эффекты используют свои фолбэки.

Ступени: `fxStep(v, max)` → v=1: 0 (эффект не рисуется), v=18: max, иначе `floor((v−1)/17 × max)`, но ≥1 при v≥2.

Палитра: body = `CLASS_BODY_PALETTE[класс].light`, accent = `CLASS_FORMATION_COLOR[класс]` (explorer `#f59e0b`,
янтарь кончика хвоста), light = `#cfe8ff` (общий). Других цветов в эффектах нет (только их осветления/затемнения
и opacity); проверяется тестом на разметке.

## 6. Известные баги и техдолг

1. **Кристаллы Discipline за канвасом:** силуэты L2–L5 почти во всю ширину канваса 200×240, окружность с безопасным
   зазором выходит за край (радиус 118–132px; при v=18 вне 0..200 × 0..240: L1 — 0, L2 — 6, L3 — 2, L4 — 6, L5 — 6
   из 6 кристаллов). В Playground
   видны за рамкой (`overflow: visible`), на HomePage обрезаются hero-блоком. Нужно решение владельца (уменьшить ассет
   в канвасе, эллиптическая орбита или ослабить зазор).
2. Нет вспышки/частиц при смене ассета-тира.
3. Аура и rim light захардкожены cyan `#38bdf8` — не по классу (это палитра тиров, вне системы атрибутов).
4. `getFoxTierConfig` с `tier` без `level` маппит тиры иначе, чем по уровню (мёртвая ветка).
5. Ассеты лежат TS-массивами в бандле (~1.15 МБ JS) — нужен code-split / lazy-load по тиру.
6. Плейграунд `/dev/avatar` открыт в проде без защиты.
7. Тировые искры по-прежнему тёплые/cyan (не из палитры атрибутов) — это FX тира, оставлен как есть.
