### Аватар

- **16.09.2026** — Аватар как параметрический векторный рендер из `AvatarParams` (engine отдельно от рендера).
- **20.09.2026** — 7 тиров эволюции: L1–2, L3–4, L5–9, L10–19, L20–34, **L35–49, L50+** (добавлены, т.к. L20 достигается
  за 2–4 месяца). Расчёт: при ~3.5 ч/день L20 ≈ 3.5 мес, L35 ≈ 11 мес, L50 ≈ 23 мес.
- **20.09.2026** — Поворот к **low-poly** (ветка `feature/lowpoly-avatar-style`), тотемные животные:
  Warrior=Волк, Creator=Ворон, Explorer=Лиса (эталон), Strategist=Сова, Wanderer=Олень. Каждое животное — своя папка
  `creatures/<animal>/`, ModularAvatar только выбирает существо.
- **23.09.2026** — **Asset-driven**: на тир — готовый SVG (векторизация AI-референса), зоны размечены вручную id групп.
- **24.09.2026** — 5 ассетов Лисы (L1 клубок, L2, L3, L4 двуногая, L5 кицунэ); **Zero Mesh Mutation**; **FX-матрица**
  (rim glow, частицы, аура, цветокоррекция) различает формы с одинаковым силуэтом; смена тира — мгновенная замена ассета.
- **03.10.2026** — Зоны берутся только из `<g id>` SVG через `annotateFoxZones.mjs`; никаких захардкоженных bbox.
- **04.10.2026** — Endurance = шрамы + вены на ногах (1..5 на всю фигуру); Focus = DoF + виньетка + частицы;
  Discipline без наклона.
- **05.10.2026** — Discipline = 6 CSS-3D кристаллов на безопасном поясе; палитры тела по классам (`CLASS_BODY_PALETTE`).
- **выжимка** — Арка лисы (kitsune): свернувшийся лисёнок → четвероногая → переход к прямохождению → двуногая
  лиса-гуманоид → кицунэ с несколькими хвостами. Переход тира прячется за вспышкой/частицами.
- **выжимка** — Каждый класс: свой цвет тела + контрастный акцент. Волк: красное тело, белые акценты.
- ~~**выжимка** — Спецификация атрибутов Лисы v1~~ — ОТМЕНЕНА 21.11.2026 (см. ниже).
- **21.11.2026** — **Атрибуты v2: единая универсальная система для всех классов** (`ui/ModularAvatar/attributeFx/`):
  палитра только body / accent / light (`#cfe8ff`); анатомия существа через адаптер (head/torso/eyes/limbs/tail),
  все якоря вычисляются геометрически; seed = id персонажа + атрибут; ступени `fxStep` (v=1 — эффекта нет).
  Strength — гребень по nape + контраст торса; Endurance — шрамы (до 4); Intelligence — нейросеть на лбу (до 10
  фасетов, единственная анимация — волна раз в 4 с); Focus — виньетка + блики глаз (тело не трогается); Discipline —
  3D-кристаллы accent, порядок по окружности растёт со значением; Social — созвездие за аватаром; Creativity — «Знак»
  по рёбрам меша. Полная таблица — `avatar-system.md` §3.
- **21.11.2026** — Пространство вокруг аватара разделено: верхние 35% канваса — только Social (≤5 звёзд), нижние 65%
  по бокам и снизу — только Discipline (16 слотов на эллипсе). Размер аватара в канвасе НЕ меняется (уменьшение отвергнуто).
  Разброс тона торса от Discipline удалён — «Новичок» = чистый ассет.
- **21.11.2026** — Визуальные изменения аватара Claude проверяет сам через Playwright по скриншотам; владельцу не присылает.
- **21.11.2026** — **Атрибуты: аспект + круг рун (текущее решение).** Тело аватара не несёт эффектов атрибутов.
  Главный атрибут (максимум ≥ 3, ничья → порядок strength…creativity) — «аспект»: красит rim light и ауру
  (× intensity 0.35→1.0), во всех классах, заливка тела не меняется. Все 7 атрибутов — кругом из 7 рун вокруг
  аватара (Сила сверху, по часовой; состояния 1 / 2–5 / 6–11 / 12–17 / 18; руна аспекта ×1.15; тултип; вспышка
  400 мс при росте). Подробно — avatar-system.md §3.
- **21.11.2026** — **Эффекты атрибутов на теле v2 — ОТЛОЖЕНЫ (не отменены).** Причина: 7 каналов мелких эффектов
  не считываются на маленьком размере и превращаются в кашу на высоких значениях. Где лежит: тег
  `avatar-attribute-fx-v2`, ветка `archive/avatar-attribute-fx-v2`, код в `ui/ModularAvatar/attributeFx/`;
  включается переключателем «Старые эффекты атрибутов (v2)» в Playground (`legacyFx=1`).
- **21.11.2026** — Правки аспекта: аспект только при строгом максимуме (любая ничья → нет аспекта); без аспекта
  контур и аура мягкий белый `#e2e8f0` × 0.5 (cyan — только Intelligence; холодные тировые искры тоже стали
  белыми); Focus = бирюзовый `#2dd4bf`; светящиеся кончики хвостов берут цвет аспекта; руны 2–5 — opacity 0.7→0.85.
- **21.11.2026** — Руны в карточках характеристик (общий `AttributeRune`), титул навыка под аватаром
  (`SkillTitlePlate`, ранги Новичок…Грандмастер) и карточки навыков с кольцом формы.
- **22.11.2026** — Иконки навыков — `lucide-react` по ключевым словам (без совпадения — руна атрибута). Сигил
  аспекта (крупная руна аспекта за аватаром, 0.78 × кольцо, opacity 0.18→0.45, оборот 60 с). Кольцо рун «живое»:
  вращение 120 с, парение рун, дыхание свечения ≥ 12, пауза на тултипе, всё выключается `prefers-reduced-motion`.
  Онбординг не создаёт навыки (навыки — только из квестов).
- **21.11.2026** — Тировые частицы зависят ТОЛЬКО от тира (связь с Focus и Discipline удалена); rim light статичен.
- **выжимка** — Волк: референсы плоские low-poly, строго анфас, спокойная прямая поза, пустой чёрный фон.
- **выжимка** — Птицы (Ворон, Сова) — своя логика крыльев.
